# Amara Suite
[Vercel](link)

Sitio web desarrollado como proyecto práctico para aplicar y reforzar conocimientos de desarrollo web frontend.

Amara Suite es una página de presentación de un alojamiento exclusivo, diseñada para mostrar sus instalaciones, experiencias y opciones de reserva.

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass (SCSS)
- JavaScript
- Bootstrap 5
- AOS (Animate On Scroll)

## Características

- Diseño adaptable a distintos tamaños de pantalla.
- Navegación entre diferentes secciones.
- Galería de imágenes.
- Sección de experiencias y lugares de interés.
- Formulario de reservas.
- Animaciones al desplazarse por la página.

## Estructura del proyecto

- `index.html`: página principal.
- `pages/`: contiene las páginas internas.
- `scss/`: archivos Sass organizados por secciones y componentes.
- `styles/`: hojas de estilo CSS compiladas.
- `assets/`: imágenes, iconos y recursos gráficos.

## Cómo utilizar el proyecto

1. Cloná el repositorio:

   ```bash
   git clone https://github.com/Yamila-Navas/01-proyecto-ccs.git
   ```

2. Ingresá a la carpeta del proyecto:

   ```bash
   cd 01-proyecto-ccs
   ```

3. Abrí el archivo `index.html` en tu navegador.
